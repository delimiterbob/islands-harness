# Objections

This repository is the objection intake for [islandsofstability.com](https://islandsofstability.com).
File an objection with the [objection form](../../issues/new?template=objection.yml). It can bear on a
proposition, a test or its pre-registration, a prior owner, or any number on the site, not only on the
harness.

## What happens to an objection

1. It gets the `objection` label and a public answer in its issue.
2. If it changes a proposition's text, it is accepted. The minor version moves, and the changelog on the
   [theory page](https://islandsofstability.com/theory#changelog) credits it and links the issue.
3. If it still stands after the answer, it is listed as open in the
   [open-objections table](https://islandsofstability.com/theory#open-objections) with its source.
4. If it shows a flaw in a test that has already run, the run's note records it, and the test's result is
   reported with the flaw beside it. Nothing is re-run quietly.

Only objections from outside the author's own review rounds count as external objections. The counter on
the theory page started at zero, and objections from reviews the author commissioned are attributed but not
counted.

## What makes an objection useful

- The exact wording or number, quoted and linked. Each proposition has a permanent anchor of the form
  `theory#v0.2-p3`.
- Evidence: data, a counterexample, a derivation, or published work with its DOI.
- What would settle it: the observation or test whose result would show you right or wrong.

Problems with the harness itself, such as a failing test or a wrong install step, can be filed as ordinary
issues.
